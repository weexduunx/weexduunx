3. Workflow Complet de Paiement

Le client sélectionne Wave/OM, le système initialise la facture avec Paydunya, redirige vers la page de paiement, puis valide le paiement via Paydunya. Le système enregistre le paiement dans la base de données et envoie un email de confirmation.

sequenceDiagram Client->>+Livewire: Sélectionne Wave/OM Livewire->>+Laravel: POST /api/payments/init Laravel->>+Paydunya: Crée facture Paydunya-->>-Laravel: URL de paiement Laravel-->>-Livewire: Retourne URL Livewire->>Client: Redirection vers Paydunya Paydunya->>Client: Page de paiement Client->>Paydunya: Valide paiement Paydunya->>Laravel: Webhook (callback) Laravel->>Base de données: Marque comme payé Laravel->>Client: Email/SMS de confirmation
